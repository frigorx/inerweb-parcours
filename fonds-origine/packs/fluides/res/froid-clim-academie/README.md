# Froid Clim Académie

Base de site pédagogique interactif pour cours de froid et climatisation.

## Contenu de cette première version

- parcours de 8 modules : cycle, pressions, surchauffe, fluides, étanchéité, électricité, mise en service, diagnostic ;
- animation du cycle frigorifique ;
- simulateur de température d'évaporation, condensation, surchauffe et sous-refroidissement ;
- atelier diagnostic avec symptômes et hypothèses ;
- quiz automatique de fin de séance.

## Intention pédagogique

Le site est pensé pour une projection en classe ou une utilisation élève en autonomie. Chaque notion doit pouvoir devenir une manipulation courte :

1. observer un phénomène ;
2. modifier une valeur ;
3. formuler une hypothèse ;
4. vérifier avec un quiz ou un cas de panne.

## Prochains cours interactifs à ajouter

- relation pression-température avec table fluide sélectionnable ;
- calcul tCO2e et seuils de contrôle d'étanchéité ;
- simulateur de tirage au vide et tenue en pression azote ;
- jeu de classement des fluides : HFC, HFO, naturel, mélange ;
- parcours CERFA formation avec filigrane et correction enseignant ;
- générateur de fiche TP et grille d'évaluation.

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucun serveur n'est necessaire pour cette version.
