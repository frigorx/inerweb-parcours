Ce qu’il faut retenir

  • La règle R‑xyz sert à décoder les halocarbures saturés, pas les mélanges.
  • Pour R‑xyz : C = x + 1, H = y − 1, F = z, puis Cl est calculé avec les liaisons restantes.
  • 0xx / 1xx / 2xx : familles du méthane, de l’éthane et du propane. Pour un composé cyclique, le C placé devant est indispensable, par exemple R‑C318 ; « 300 » n’est pas à lui seul le nom d’une famille équivalente aux séries 400 ou 500.
  • 400 : mélanges zéotropiques. 500 : mélanges azéotropiques. 600 : organiques divers. 700 : inorganiques. 1000+ : organiques insaturés.
  • Une lettre finale minuscule distingue un isomère ; une majuscule distingue une composition de mélange.
  • R‑407A, B et C contiennent les mêmes composants R‑32 / R‑125 / R‑134a avec des pourcentages différents.
  • Les naturels ne forment pas une série unique : R‑50, R‑170, R‑290, R‑600a, R‑717, R‑718, R‑744 ou R‑1270 appartiennent à plusieurs tranches.
  • Avant toute intervention : étiquette équipement, fiche de données de sécurité et documentation fabricant.
