# Le circuit d’huile — entrée interactive

Cette page est l’entrée unique de la ligne pédagogique. Elle ne remplace aucun des dix
modules : elle les rend visibles dans leur ordre, sous forme de carte de métro, puis ouvre
la station choisie.

## Contrat

- une seule page plein écran, sans défilement ;
- dix stations toutes accessibles au clavier et au toucher ;
- fonctionnement local, sans réseau ni dépendance ;
- carte de navigation explicitement distinguée d’un schéma fluidique ;
- retour possible vers cette ligne depuis chaque module ;
- état imprimable sous forme de liste textuelle ;
- statut : brouillon à relire, non publié et non indexé au RAG actif.

Les modules détaillés conservent leurs propres sources techniques, leurs SVG manuels et
leurs questions de préparation au niveau habilitation fluides.
