## Commande à lancer le moment venu

Une fois les textes validés par F. Henninot, depuis `C:\git\atelier-animations\refonte` :

```
node voix/fabriquer.mjs --tout
```

(ou capsule par capsule : `node voix/fabriquer.mjs lire-le-code`). L'option `--tout`
est nécessaire : sans elle, le script saute tout MP3 déjà présent — or ce sont
précisément les fichiers existants qu'il faut remplacer. Une alternative plus fine :
supprimer d'abord les seuls MP3 listés ci-dessus, puis lancer `node voix/fabriquer.mjs`
sans option, qui ne refabrique que ce qui manque.

Rappel du script lui-même : il envoie les textes des narrations à Microsoft (edge-tts)
— ne le lancer qu'avec un feu vert.
